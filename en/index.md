## Featured projects

### [MyOS — Educational Unix-like operating system](https://github.com/crecabar/myos)

An open-source **x86-64** operating system written primarily in **C**, built to study how operating systems work from the boot process through user space.

- UEFI boot with **Limine**, validated in **QEMU** and on physical hardware.
- Kernel with virtual memory, ring 0/ring 3 isolation, processes, preemptive scheduling, and system calls.
- **ELF** program loading and execution; VFS, file descriptor, initramfs, and device infrastructure.
- Initial Unix-style commands integrated; the first interactive **`myos $ `** shell is in development.
- Freestanding builds with **LLVM/Clang and LLD**, **GDB** debugging, and automated testing.
- Long-term goals include a dedicated userland, **MFS** filesystem, device support, graphical environment capable of running `startx` / `xclock`, and eventually self-hosting.

**Companion projects at different stages of development:** [libc](https://github.com/crecabar/myos-libc) · [userland](https://github.com/crecabar/myos-userland) · [MFS](https://github.com/crecabar/myos-mfs) · [Vim port](https://github.com/crecabar/myos-vim)
