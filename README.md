# crecabar.github.io

CV profesional y portfolio público de **Cristian Recabarren Madrid**.

- **Sitio:** https://crecabar.github.io/
- **Contenido:** experiencia profesional, formación, competencias y proyectos destacados de GitHub.
- **Tecnología:** GitHub Pages + Jekyll (tema `jekyll-theme-minimal`).

## Fuentes

La trayectoria laboral, formación, competencias e idiomas se mantienen a partir del CV profesional. Las descripciones de proyectos se contrastan con [el perfil GitHub](https://github.com/crecabar) y sus repositorios.

## Actualizaciones

Editar `index.md` para actualizar el CV y portfolio. Los metadatos del sitio están en `_config.yml`. GitHub Pages publica desde la rama/fuente configurada en los ajustes del repositorio.

No se publican el teléfono personal ni copias del CV PDF por defecto, para reducir exposición innecesaria de datos de contacto.
